Configure automatic ticket assignment rules

Automatically assign incoming tickets to the right agent or support team based on category, priority, department, or other ticket information.

This article applies to Helpdesk 365 v4.2 and later on Teams + SharePoint, and assumes you administer Helpdesk 365 for your organization.

Before you begin

• Helpdesk 365 v4.2 or later installed in your tenant
• Helpdesk 365 admin or site collection administrator access
• Support agents and teams already configured
• Ticket categories and departments configured, if they will be used in assignment rules

Steps

1
1. Open Helpdesk 365 admin settings From the Helpdesk 365 home page, select the Settings icon, then go to: Admin Settings → Automation & Workflows → Assignment Rules
2
2. Create a new assignment rule Select Add Rule. Enter a clear name for the rule, for example: Assign IT Hardware tickets to IT Support Add an optional description explaining when the rule should be used.
3
3. Define the conditions Select the conditions that incoming tickets must meet. For example: Category is Hardware Department is IT Priority is High You can configure one or multiple conditions depending on your support process. When multiple conditions are configured, make sure the rule logic matches the expected assignment behavior.
4
4. Configure the assignment action Under Assign To, choose the required: Support agent Support team Technician group For example: Assign To → IT Support Team If your configuration supports workload-based or round-robin assignment, select the appropriate assignment method.
5
5. Set the rule priority If multiple assignment rules could apply to the same ticket, arrange the rules in the required execution order. Place more specific rules above general rules. For example: Priority 1: Critical IT Hardware tickets Priority 2: All IT Hardware tickets Priority 3: All IT tickets
6
6. Enable the rule Turn on Active or Enable Rule. Select Save to apply the configuration. New tickets matching the configured conditions will now follow the assignment rule.

Verify the configuration

Create a test ticket that matches the rule conditions. For example: Category: Hardware Department: IT Priority: High Verify that: The ticket is created successfully The correct agent or team is assigned The assignment appears in the ticket activity The assigned agent receives the configured notification Other assignment rules do not override the expected result

Troubleshooting

• Confirm that the assignment rule is enabled and that the ticket matches all configured conditions. Also verify that a higher-priority rule is not being executed first.
• Ticket is assigned to the wrong team Review the order of the assignment rules and check whether multiple rules contain overlapping conditions. Move the more specific rule above broader rules.
• Assigned agent does not receive a notification Verify that notifications are enabled for ticket assignment and confirm that the assigned user's email address is available and valid.
